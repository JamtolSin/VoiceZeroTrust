# 한국어 합성 음성 평가 데이터 조사 — 2026-09-12

## 우선 후보: DSD-Corpus v1

공식 공개 페이지: https://zenodo.org/records/13788455

공식 페이지가 연결한 메타데이터: https://drive.google.com/file/d/1l2iywJJBYh1RI5mW_KQ5xkB_9jLsC_IC/view

확인한 메타데이터 SHA-256: `b12780397d0066a8023c89814b83310761dff392f968fcd1c1672f0a132ce44d`

CSV 전체 92,385행에서 Language를 소문자로 정규화한 후 `korean`과 일치하는 29,428행을 집계했습니다. 파일 다운로드/디코딩으로 확인한 개수는 아닙니다.

공식 페이지는 CC BY-NC 4.0(비상업용)을 명시합니다. 전체 압축파일은 약 17.4GB, 9개 분할 파일입니다. 원천 음성의 권리와 개별 화자의 복제 동의를 독립적으로 확인한 것은 아닙니다. 기존 합성 음성 평가를 우선하며, 이를 추가 음성 복제 허락으로 해석하지 않습니다.

한국어 출처 그룹은 AIHUB, Elevenlabs, MeloTTS, SeamlessM4T-TTS, MMSTTS, SNS2023, SNS2024, VITS-AIHUB입니다. VITS-AIHUB가 10,595개로 합성 클래스의 대부분을 차지합니다. SNS 수집 자료는 원천 권리 확인 전 우선 제외하는 것이 적절합니다.

## 중요한 분할 문제

`Speaker name` 문자열(빈 값, `-`, Unknown/unknown 제외)을 비교하면 train과 eval 사이 257개 식별자가 겹칩니다. train/dev는 224개, dev/eval은 265개입니다. 이는 메타데이터 문자열 집계이며 실제 화자 수나 생체 신원을 검증한 결과는 아닙니다.

따라서 제공 train/dev/eval을 그대로 사용하면서 '새 화자 평가'라고 주장하면 안 됩니다. 전체 데이터를 학습에 쓰기 전에 원본·합성 파생 관계, 화자 및 텍스트 식별자, 중복 해시를 조사해 그룹 분할을 잠가야 합니다. 생성기별 성능도 별도로 보고해야 합니다.

## 다른 후보

- KoAAD: https://github.com/ldh-Hoon/KoAAD — 한국어 실제 AIHUB 및 6종 TTS 약 3만개/10GB라는 제작자 설명. 코드 라이선스와 데이터·원천 서비스의 이용 조건을 별개로 확인해야 합니다. 아직 채택하지 않았습니다.
- MLAAD: https://huggingface.co/datasets/mueller91/MLAAD — 비상업 학술 연구 제한 및 연락처 공유/접근 조건 동의가 필요합니다. 현재 한국어 포함 범위와 짝이 맞는 실제 음성은 확인하지 않았습니다. 접근 조건을 대신 수락하지 않았습니다.
- OpenSLR97: https://www.openslr.org/97/ — 한국어 실제 음성, CC BY-NC-ND 4.0. 합성 음성 정답 세트는 아니며 복제용 원천으로 자동 선택하지 않았습니다.
- KoDF: https://deepbrainai-research.github.io/kodf/ — 주로 영상 조작 데이터이므로 영상 fake 라벨을 음성 합성 라벨로 사용하지 않습니다.

## 제안하는 다음 실행

1. 비상업 연구·평가 사용인지 확인합니다. 상용 모델 학습이면 별도 허락 또는 상용 사용 가능한 자료를 확보합니다.
2. DSD 음성 파일을 로컬 비공개 경로에 받으며 제공 MD5와 로컬 SHA-256을 기록합니다. 압축 해제 경로를 검증합니다.
3. 한국어 행과 실제 파일의 매칭·길이·중복·라벨 충돌·출처를 확인합니다. SNS 수집분은 권리 확인 전 제외합니다.
4. 새 한국어 자료는 우선 학습하지 않고 고정된 기존 탐지기의 외부 진단에 사용하거나, 점수 확인 전에 학습/보정/최종 시험 그룹을 분리합니다. 두 실험 목적을 혼동하지 않습니다.
5. 사용 조건이 확인된 새 화자·생성기 최종 시험을 확보한 뒤 모델 개선과 승격을 판단합니다.

적절한 기존 합성 자료가 있으므로 현재 임의의 공개 음성을 새로 복제할 필요는 없습니다. 보충 합성이 필요하면 직접 동의받은 화자와 중립적인 대본을 사용하고, 실제/합성 정답과 사기 의도 정답을 분리합니다. 합성 탐지율을 보이스피싱 탐지율로 부르지 않습니다.

사용자가 비상업 연구·평가 제한을 승인했습니다. `scripts/prepare_dsd.py --noncommercial-research`로 공식 메타데이터 해시를 검증하고 로컬 한국어 후보 목록을 생성했습니다. 29,428개 중 SNS 출처 1,733개는 권리 확인 전 제외했고 나머지 27,695개도 실제 음성·파생 관계 검증 전 후보일 뿐입니다.

## 실행 확인 — 2026-09-13

사용자가 D:의 `D:\VoiceZeroTrust-data\dsd-corpus-v1` 사용도 승인했습니다. 9개 분할 파일 17,411,674,079바이트를 내려받아 제공 MD5와 로컬 SHA-256을 모두 검증했습니다. 새 음성 복제는 수행하지 않았습니다.
