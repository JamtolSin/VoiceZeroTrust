# VoiceZeroTrust

동의한 참여자의 짧은 음성으로 합성 음성을 체험하는 로컬 보안 교육 데모입니다.
목소리만으로 신원을 판단하지 않고, 알고 있는 번호로 콜백하는 습관을 알립니다.

## 실행 (Windows PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe app.py
```

브라우저에서 http://127.0.0.1:7860 을 엽니다. 음성 파일 업로드 또는 마이크 녹음 →
녹음에서 실제로 말한 대사 입력 → 음성 사용 동의 및 모델 이용 조건 확인 → 합성하기 → 원본과 결과를 비교 청취합니다.
첫 실행은 모델 다운로드 때문에 인터넷과 추가 저장 공간이 필요합니다.
모델은 첫 합성 요청 시 로딩하며 이후 재사용합니다. CPU에서도 실행을 시도하지만 느릴 수 있습니다.
CUDA를 사용하려면 동일 버전의 CUDA용 torch/torchaudio를 PyTorch 공식 배포에서 설치하세요.

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade torch==2.8.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu128
```

기본 엔진은 [Qwen3-TTS-12Hz-1.7B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base)이며
모델 라이선스는 Apache 2.0입니다. XTTS 어댑터는 코드에 보존하지만 UI에서는 Qwen만 사용합니다.
XTTS 가중치를 별도로 사용할 경우 해당 CPML 조건이 적용됩니다.

Qwen은 참조 음성과 정확한 대사를 함께 입력하는 모드를 사용합니다. 대사를 생략하는
화자 임베딩 전용 모드는 사용하지 않습니다. 녹음과 대사가 일치해야 하며 자동 전사는 없습니다.
RTX 3080에서는 BF16 / SDPA로 실행합니다. 첫 다운로드 이후에도 모델 로딩과 생성에 시간이 걸립니다.
현재 모델 교체가 모든 화자에서 XTTS보다 높은 유사도를 보장하지는 않습니다.

## 현재 범위

- 한국어 고정 교육 문장만 합성, 로컬 주소에서 실행
- MP3, WAV, M4A, AAC, OGG, WebM, FLAC 입력을 내부 WAV로 자동 변환
- 2~30초, 20MB 이하 입력; 기본 검증은 FFmpeg 디코딩 후 수행
- 6~10초의 깨끗한 음성 권장. 2·3·5초의 유사도를 보장하지 않음
- 재학습 없이 참조 음성과 대사를 사용하는 Qwen3-TTS 추론
- 음성의 본인 여부를 기술적으로 인증하지 않음
- 가청 합성 고지가 문장에 포함됨. 비가청 워터마크는 미구현
- 입력 음성은 외부 합성 API로 전송하지 않음
- 브라우저에서 재생되는 음성은 저장/녹음 가능하며 DRM을 제공하지 않음

## 파일과 개인정보

합성 작업 파일은 성공/실패 후 정리합니다. Gradio의 입력/출력 재생 캐시는 `.runtime/gradio`에
저장되며 60초마다 15분 이상 된 캐시를 정리합니다. 화면 초기화는 UI만 비웁니다.
프로세스 강제 종료 시 캐시가 남을 수 있습니다. 원본 업로드 파일은 변경/삭제하지 않습니다.
`.runtime`은 Git에서 제외됩니다. 현재 작업 폴더가 OneDrive 안에 있으면 캐시도 동기화될 수
있으므로 민감한 녹음 실험은 동기화되지 않는 로컬 폴더에 프로젝트를 두고 실행하세요.

## 검증

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

테스트는 합성 엔진 대역을 사용해 입력 검증, 고정 문장, 결과 반환과 임시 파일 정리를 검증합니다.
실제 음성 유사도와 GPU 합성 검증에는 이용 조건 확인과 동의한 참여자의 녹음이 필요합니다.

공식 Qwen 예제 참조 음성으로 실제 실행 경로를 검사하려면
`.\.venv\Scripts\python.exe scripts/smoke_qwen.py`를 실행합니다.
공식 예제 음성을 다운로드하고 고정된 한국어 교육 문장만 생성합니다.
2026-09-10 RTX 3080 로컬 확인: 출력 9.28초, 처리 22.4초(캐시된 모델 로딩 포함).
이는 실행 검증이며 한국어 화자의 유사도 비교 평가 결과가 아닙니다.

## 합성 → 탐지 성능 평가

[실험 결과 인덱스](experiments/README.md)에서 날짜·모델·데이터셋별 결과와 탐지 버전을 확인할 수 있습니다.

`scripts/smoke_evaluation.py`로 MP3 입력부터 새 합성, 실제 탐지, O/X 비교까지 실행합니다.
여러 화자의 동의된 녹음 수집·라벨 쌍 생성·오탐/미탐 측정 명령은
[평가 실행 가이드](docs/evaluation.md)를 참고하세요. 합성 탐지와 사기 의도 판별은 다릅니다.
