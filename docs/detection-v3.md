# 오탐 감소 실험 v0.3

새 모델로 기본 서비스를 교체하지 않았습니다. 이 버전은 학습 규제·보수적 경고 기준·잡음/대역 제한 증강의 효과를 측정하는 개발 실험입니다.

[전체 측정표 및 한계](../experiments/2026-09-12/aasist-aug-lowfpr__stafford-groupcv/README.md)를 먼저 확인하세요.

## 폴더 역할

- `src/evaluation/augmentation.py`: 동일한 입력과 식별자에서 항상 같은 증강을 생성합니다.
- `scripts/prepare_v3_features.py`: Stafford 개발 음성만 읽고 특징을 추출합니다. 음성과 특징은 `.runtime/evaluation/detection-v3`에만 보관합니다.
- `scripts/evaluate_v3.py`: 출처 그룹 5분할 시험, 내부 학습/보정 분리, 사전 고정한 4개 설정 비교.
- `scripts/archive_detection_v3.py`: 음성·개인 경로·임베딩 없이 측정 결과와 분류기 파라미터를 보관합니다.
- `tests/test_detection_v3.py`, `tests/test_experiment_v3_archive.py`: 증강 재현성, 분할 누출 방지, 개별 예측 기반 지표 재계산과 체크섬 검사.

원본은 1,650개입니다. 파생 버전까지 4,950개 특징을 만들었지만 독립 표본이 4,950개라고 세지 않습니다. 이전 DeepVoice 시험은 이번 학습이나 기준 보정에 사용하지 않았습니다.

## 다음 단계의 조건

한국어 데이터의 사용 조건이 아직 확인되지 않아 한국어 학습은 진행하지 않았습니다. 새로운 독립 평가 데이터도 필요합니다. 현재 결과를 본 뒤 같은 시험에 맞춰 반복 조정하고 이를 새 성능으로 발표하면 안 됩니다.

실제 통화 코덱·재녹음과 새 데이터 확보 후, 데이터·모델·임계값을 다시 고정한 별도 실험을 만들어야 합니다. 현재 잡음 후보의 합성 탐지율은 3.33%로 배포 근거가 부족합니다.
