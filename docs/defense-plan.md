# 방어 기능 배치와 PR 순서

기존 합성 교육 데모(app.py, 7860)를 보존하고 main 기반 독립 PR 세 개로 추가한다.

| 단계 | 폴더 / 실행 파일 | 범위 | 검증 |
|---|---|---|---|
| 1 | src/detection, detection_app.py (7861) | 음향 합성 흔적, 로컬 ASR, 사기 행동 규칙 분석 | 입력 검증, 채널 실패 격리, 교육/인용 오탐 사례 |
| 2 | src/watermark, watermark_app.py (7862) | 생성된 교육 음성에 AudioSeal 표식 삽입 및 독립 검출 | 무표식 대조군, 출력 재검출, 메시지 해석 |
| 3 | src/protection, protection_app.py (7863) | 원본 표식과 변환·외부 복제 결과의 검출 비교 | 길이별 크롭, 압축, 리샘플링, 대조군, 재현 설정 |

각 단계는 대응 tests/test_*.py와 docs/*.md를 둔다. 원본·모델·결과 파일은 .runtime 아래 두고 Git에서 제외한다.
단계별 실행 파일 분리로 main 기준 독립 검토 및 병합이 가능하다. 초기에는 동일 라이브러리의 작은 어댑터가
두 연구 모듈에 있을 수 있다. API가 안정된 후 별도 변경으로 공통화한다.

음향 분석 점수, 대화 행동 근거, 워터마크 검출은 한 숫자로 합치지 않는다. 보정되지 않은 점수를
사기 확률로 표현하지 않는다. 워터마크 미검출은 사람의 원본이라는 증거가 아니며, 표식 존재도
신원·발화 사실·사기 의도를 증명하지 않는다. 공개 메시지는 암호학적 인증이 아니다.

원본 파일에 삽입한 표식의 음성 복제 후 전이는 연구 가설이다. AudioSeal은 학습 방지 솔루션으로
표현하지 않는다. 실험 실패·짧은 파일·모델 미설치는 별도 상태로 남긴다. 전용 Timbre Watermarking /
VoiceMark 기법 통합 및 한국어 코퍼스 학습은 이 MVP에 포함하지 않는다.

평가 확장: 화자와 생성기를 기준으로 데이터 분리, 처음 보는 생성기/Qwen 평가, 정상 통화 오경보율,
2/3/5초 길이별 탐지율, 재녹음·전화 코덱 조건. 현재 단위/스모크 테스트는 이 성능 평가를 대체하지 않는다.
