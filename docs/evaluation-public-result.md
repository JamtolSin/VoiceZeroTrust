## 해석과 제한

기존 모델은 이 코퍼스의 합성 파일 약 29%를 놓치고 실제 음성 약 22%를 잘못 표시합니다. 단독 차단이나 음성 기반 신원 인증 근거로 사용하기 어렵습니다.

영어 음성의 합성 여부 측정이며 한국어 보이스피싱 의도, 통화 환경, 최신 Qwen 생성물 성능은 측정하지 않았습니다. 이번 실행에서 새 복제 음성을 만들지 않았습니다. 실제 음성은 14개 원본 녹음의 파생 클립이어서 파일 수를 독립 화자 수로 해석할 수 없고, 중복 제거로 모든 상관성이 제거되지 않습니다. 게시자의 이용 조건에 따라 로컬 방어 평가만 수행했으며 화자별 동의는 독립 검증하지 않았습니다.

## 결과 및 재실행

`.runtime/evaluation/public-stafford-v4/`에 원본 parquet, 음성, manifest.json, predictions.json, report.json, config.json이 있습니다. 원본 음성과 경로는 Git에 포함하지 않습니다. 현재 OneDrive 경로의 OS 동기화는 별도 통제해야 합니다.

```powershell
.venv\Scripts\python.exe -m pip install pyarrow==25.0.1
.venv\Scripts\python.exe scripts/benchmark_public.py
```

완료된 파일은 체크포인트를 재사용합니다. 새 추론을 수행하려면 스크립트 출력 경로를 새 디렉터리로 변경합니다. 데이터 revision 또는 실행 설정 변경 시 기존 결과와 혼합하지 않고 중단합니다.
