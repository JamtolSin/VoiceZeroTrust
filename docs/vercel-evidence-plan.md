## 성능 비교 원본

- `experiments/2026-09-13/aasist-korean__dsd-v1-grouped/test-report.json`
- 같은 폴더의 `README.md`: 한국어 test 4,660개, 생성기별 XLS-R/v2/v4 비교.
- `docs/evaluation-smoke-result.md`: 실제 Qwen 생성 → XLS-R 탐지 1쌍. 합성 1개 미탐. 일반 탐지율로 확대 해석하지 않는다.
- v4는 비상업 연구용이다. 전체 합성 탐지율 91.24%, 정상 오탐률 3.29%이지만 MMSTTS 탐지율 13%, 잡음 부분집합 오탐률 75%로 실전 승격 기준에 실패했다.

저장된 평가 결과와 이번 배포에서 실행한 결과를 구분한다. 합성 판별을 보이스피싱 의도 판별 또는 신원 인증으로 표현하지 않는다. 배포 성공 화면은 실제 배포 완료 후 캡처한다.
