# 원본 보호 실험 (3단계)

독립적인 main 기반 기능입니다. 1·2단계 모듈을 import하지 않습니다.

```powershell
python -m pip install -e .
python -m pip install -r requirements-protection.txt
python protection_app.py
```

http://127.0.0.1:7863 에서 본인 또는 동의받은 2~30초 녹음을 넣습니다.
AudioSeal 공식 생성기/탐지기를 CPU에서 지연 로딩하며 첫 실행에 모델 다운로드가 필요합니다.
오디오 원본은 다운로드 서비스로 전송하지 않습니다. MP3/WAV/M4A 등 기존 입력 지원 형식과 20MB 제한을 사용합니다.

## 실험 조건

- 원본을 mono 16kHz로 정규화하고 피크 0.9 여유를 확보합니다.
- 고정 16비트 0 메시지를 삽입합니다. 이는 인증 코드나 암호가 아닙니다.
- 워터마크 삽입 결과의 피크가 1을 넘으면 대조군·실험군 모두 같은 계수로 줄입니다.
- 양 군에 identity, MP3 64kbps, 8kHz→16kHz, 시작점 0에서 2/3/5초 자르기를 동일 적용합니다.
- 입력보다 긴 crop은 건너뛰었다고 기록합니다. 오디오의 언어·말하기 속도·품질에 따라 결과는 달라집니다.
- raw_presence_score는 AudioSeal positive frame probability의 평균입니다. 0.5는 미보정 실험 임계값입니다.
- `unmarked_control`은 이번 실행에서 새 표식을 추가하지 않은 대조군이며, 기존 워터마크가 없음을 인증하지 않습니다. 높은 점수는 기존 표식 또는 오탐일 수 있습니다. 한 파일로 전체 오탐률을 추정하지 않습니다.
- 선택한 외부 재녹음·복제 결과는 원본과의 연결을 확인할 수 없으므로 lineage를 미검증으로 기록합니다.

보고서는 모델 이름·라이브러리 버전·설정·길이·점수만 담고 파일 경로, 음성, 전사문을 담지 않습니다.
임시 변환 파일은 성공·실패 후 TemporaryDirectory로 삭제합니다. UI 결과는 Gradio 로컬 캐시에
최대 약 11분 보관됩니다. 초기화 버튼은 화면을 비우며 캐시 즉시 삭제를 보장하지 않습니다.

## 해석의 한계

이 도구는 학습 방지나 음성 복제 후 워터마크 전달을 구현·보증하지 않습니다.
AudioSeal 검출은 신원 인증이나 사기 판단이 아닙니다. 표식이 없어도 합성일 수 있고, 사람의 녹음에도 표식을 넣을 수 있습니다.
복제 후 전이를 연구하려면 각 원본/변환 관계가 검증된 반복 실험과 독립 생성기·화자 대조군이 추가로 필요합니다.

공식 API와 모델: https://github.com/facebookresearch/audioseal

