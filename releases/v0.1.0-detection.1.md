# VoiceZeroTrust Detection v0.1.0-detection.1 — 실험용 사전 릴리스

현재 XLS-R 탐지 파이프라인과 공개 코퍼스 실측 결과를 함께 보관하는 첫 탐지 스냅샷입니다. 새 모델 학습이나 성능 개선 릴리스가 아닙니다. main 대상 PR은 별도 검토 대상으로 남기며, 이 릴리스 태그는 실험 결과 브랜치의 검증된 커밋을 가리킵니다.

## 중요한 한계

한국어 보이스피싱 의도가 아닌 **영어 합성 여부** 측정입니다. 216개 완전 중복 파일이 있었으며 실제 음성은 14개 녹음에서 나눈 클립입니다. 탐지기 학습 데이터와의 중복 여부는 미확인입니다. 최신 Qwen 생성 성능을 대표하지 않으며, 단독 신원 인증·금융 차단용으로 사용하지 마세요. 원본 음성·전사문·로컬 개인 경로는 릴리스에 포함하지 않습니다.
